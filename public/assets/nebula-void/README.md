# nebula-void

VOID environment plate. Magenta and deep violet.

- Type: Background
- Aspect ratio: 16:9
- Resolution: 3840 x 2160

Must fall to true black at every edge; the composition depends on the frame corners staying black. Replaces the procedural volume in src/experience/environments/NebulaVolume.tsx.

This folder is intentionally empty in Phase 1. The application runs normally
without it. See the root README, "Phase 2 asset slots".
